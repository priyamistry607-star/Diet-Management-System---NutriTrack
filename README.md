## 📖 About the Project

**NutriTrack** is a full-stack web application developed to make healthy living simple and accessible.

The system allows users to track their daily meals, calculate calorie intake, monitor nutrition, record exercise activities, and receive personalized diet plans. It also provides a dedicated dashboard for dietitians to manage appointments and assist users with their health goals.

Whether your goal is **weight loss, weight gain, or maintaining a healthy lifestyle**, NutriTrack helps you stay on track with an easy-to-use interface.
