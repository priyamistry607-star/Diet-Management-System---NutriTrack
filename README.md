# Diet-Management-System---NutriTrack
NutriTrack is a full-stack Diet Management System that helps users track calories, nutrition, meals, and exercise while offering personalized diet plans, appointment management, secure authentication, and dedicated dashboards for users and dietitians.
🥗 NutriTrack – Diet Management System

NutriTrack is a full-stack web application designed to promote healthy eating habits and simplify diet management. The platform enables users to monitor their daily calorie intake, nutrition, meals, and physical activities while providing personalized diet plans based on their health goals.

The system includes two different user roles:

👤 User Dashboard
User Registration & Login
Daily Meal Tracking
Automatic Calorie Calculation
Nutrition Monitoring
Exercise Tracking
Weekly & Monthly Progress Reports
Personalized Health Goals
Profile Management
👨‍⚕️ Dietitian Dashboard
Secure Dietitian Registration
Appointment Management
Patient Monitoring
Diet Plan Recommendations
Schedule Management

🎯 Project Objective

The objective of NutriTrack is to help individuals adopt healthier lifestyles by providing an easy-to-use platform for diet planning, calorie tracking, nutrition management, and professional dietitian consultation.
